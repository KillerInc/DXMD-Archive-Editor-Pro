# DXMD Archive Editor Pro v0.7.8

## Compact Research Inspector list

- The left research table now contains only three columns:
  - **Status**
  - **Attribute**
  - **User ID**
- Removed Context, Logical Resource, Payload Offset, Internal Resource, Chunk, Resource Offset, and Archive Offset from the left table.
- Those details are still available in the selected-row inspector on the right; no research metadata was removed.
- The left list pane is slightly narrower, giving the detailed inspector more working space.

All v0.7.7 Base/DLC HeaderLib mappings and editing behavior remain unchanged.

Java 21 or newer remains required.
