# DXMD Archive Editor Pro v0.6.8

## Changes from v0.6.7

- Fixed the DLC **Compare** columns not appearing until a comparison dropdown was manually reselected.
- Default DLC comparison selections are now established before the table structure is built.
- DLC comparison hex cells now populate immediately when a DLC tab first opens.
- Added regression coverage for the DLC comparison-column initialization issue.
- Kept the existing archive-editing, backup, restore, research-profile, warning, and User ID workflows unchanged.

## Notes

This release is built for Java 11 or newer. As with previous versions, keep game saves backed up when testing suspected or inventory-dimension fields.
