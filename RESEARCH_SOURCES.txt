DXMD ARCHIVE EDITOR PRO - RESEARCH SOURCES
Last updated: 2026-10-06

PURPOSE
This file records external DXMD reverse-engineering/modding sources already researched,
what each source establishes, and how that information has been used by the editor.

IMPORTANT METHODOLOGY
The editor's existing confidence methodology is unchanged:
CONFIRMED / STRONG_SUSPECTED / SUSPECTED / UNIDENTIFIED.
External information is used only when it supports an existing mapping or provides a
concrete new identification. Nearby names, record-family labels, or general mod claims
are not treated as proof of a specific byte.

1. GROGNouGNOU - DXMD MODDING TUTORIALS
======================================================================
URL:
https://www.grognougnou.com/mods-tutorials-deus-ex-mankind-divided.html

Status:
VERIFIED SOURCE by project owner. Treat clearly stated technical information on this
page as verified DXMD information. When the page itself says a meaning is uncertain
or possible, preserve that uncertainty.

Major archive/DLC structure:
- Game.layer.1.all.archive contains much of the compact gameplay data used by mods.
- DLCPackAssault.layer.0.all.archive = Elite Assault Rifle + CHAFF upgrade.
- DLCPackClassic.layer.0.all.archive = Classic Revolver.
- DLCPackEnforcer.layer.0.all.archive = Elite Combat Rifle.
- DLCPackIntruder.layer.0.all.archive = Elite 10mm Zenith Pistol.
- DLCPackTactical.layer.0.all.archive = Elite Tranquilizer Rifle + Disassembler augmentation.

Verified item/inventory functions:
- 8BB5F8E1 = inventory length for most items.
- 8E6BC587 = inventory length for firearms/multitools/special items.
- 0E609B24 = inventory height for ammo/grenades/mines/consumables/etc.
- 5FA99754 = inventory height for multitools/Jammer/Killswitch.
- 8D0137A2 = stack amount.
- Base records commonly use 17 00 00 00 separators.
- DLC inventory records commonly use 09 00 00 00 separators.
- Small firearms such as pistol/revolver/stun gun have inventory-size limitations.

Verified price functions:
- 2A28DFE5 = consumable item price.
- B9B2FE47 = machine parts / disassembly / some upgrade / grenade/mine/etc. price family.
- 20EDD36A = multitool price.
- C8E9D6EF = 5.56mm ammo price.
- ED3C00CD = 10mm ammo price.
- 0E90F2F6 = shotgun ammo price.
- 4A2034A4 = 40mm ammo price.
- 6C8E04FF = 7.62mm ammo price.
- 6038AA15 = 9mm ammo price.
- 594FCED0 = revolver ammo price.
- 5697B650 = stun gun ammo price.
- 015248E0 = tranquilizer ammo price.
- EF482EB8 = .416 ammo price.
- CD7BD3AF = shotgun EMP ammo price.
- 56CFB420 = revolver EMP ammo price.
- 76771038 = 9mm EMP ammo price.
- 0344B883 = 5.56mm EMP ammo price.
- 0C092EF3 = 10mm EMP ammo price.
- 28084B16 and 0B06F865 = unidentified EMP-ammo price records.
- 9A590F0A = weapon price (except Grenade Launcher).
- B368F1C3 = Grenade Launcher price.
- A76435AB = EMP grenade/mine price.
- A463A1F8 = gas grenade/mine price.
- 563E4A81 = frag grenade/mine price.
- 16C64E9C = concussion grenade/mine price.
- E856DF13 = smoke grenade/mine price.

Verified consumable/effect functions:
- 4A376618 = blurred-vision duration.
- F1F9CDA5 = normal health recovery.
- E1B6D572 = special/alcohol health recovery.
- 72C142AA = Biocell energy recovery.
- 8B658735 = Micro-Assembler spare-parts crafting cost.
- 65000977 = number of items crafted per recipe/action.

Verified weapon base/upgrade functions:
- 79D898E8 = base magazine capacity.
- 3D96AB5F = cumulative upgraded magazine-capacity bonus.
- 77731DD6 = weapon-upgrade stage/level marker (01/02/03).
- 585B7C22 = spare-parts cost for a weapon customization/upgrade.
- EA10EDF8 = base firing timing / shot duration component.
- F8861A4C = delay-before-next-shot component.
- D42EB87C = third base rate-of-fire component.
- 72365784 = rate-of-fire upgrade bonus.
- 6712F5D4 = alternate rate-of-fire upgrade bonus.
- A1B89DD4 = weapon range.
- 5F317320 = base reload speed.
- FA600225 = reload-speed upgrade bonus.
- 2B4352B8 = functional weapon damage bonus/malus used in upgrade records,
  including SILENCER downgrade records.
- 915125A7 and E168CFB1 are damage-related bonus fields, but the source only
  proposes that they may relate to medium/long range. Do NOT mark those exact
  meanings confirmed without additional evidence.

CRITICAL visual-vs-functional distinction:
- 0519EE4D affects weapon damage DISPLAY only; it does not change real weapon power.
- SILENCER records use 0519EE4D with signed display modifiers including:
  D8 FF FF FF (-40), F1 FF FF FF (-15), F6 FF FF FF (-10),
  FB FF FF FF (-5), E2 FF FF FF (-30), E7 FF FF FF (-25),
  EC FF FF FF (-20), plus other documented values.
- Functional damage modification is separate and uses gameplay-stat fields such as
  2B4352B8.
- This distinction was applied to RawArchiveAuditCatalog: previously ambiguous
  suppressor "Component B" rows matching these signed display values were promoted
  to confirmed visual damage-display modifiers.

Verified augmentation/energy functions:
- 379F683F is commonly used for augmentation energy use, BUT the same function code
  is also used for FOV/camera parameters. Context is required.
- 22C6ABC4 = takedown energy-use function. The adjacent float is the energy cost.
- 4C1BC5B1 = player's automatic/base energy-regeneration amount.

Weapon upgrade block organization:
- Weapon base stats live in weapon paragraphs.
- Upgrade bonuses live in separate AMMO_CAPACITY_, DAMAGE_, RATE_OF_FIRE_,
  RELOAD_SPEED_, RECOIL_, SILENCER, FIRE_PATTERN and related records.
- Upgrade records often do not identify the owning weapon directly.
- AMMO_CAPACITY stages are cumulative: stage 2 includes stage 1; stage 3 is total.
- The same elimination/test method applies to other weapon upgrade families.

4. SILENCE TO THE GUNS
======================================================================
URL:
https://www.nexusmods.com/deusexmankinddivided/mods/43?tab=docs

Useful discoveries:
- Built-in silencer behavior can be enabled separately from SILENCER add-on stat modifiers.
- The built-in-silencer function does not itself modify weapon stats.
- Silencer add-on stat/behavior modifications still apply independently when attached.
- Built-in silencing is reported to work for nearly all weapons except Devastator Shotgun
  and Grenade Launcher.
- Bolt-action -> semi-auto conversion applies to Stun Gun, Tranquilizer Rifle and Lancer Rifle.
- Applying some function-slot changes to an existing save may cause standard reticles to
  disappear; starting a new game avoided the observed problem.
- This source supplied controlled archive comparisons used to confirm several function-slot,
  built-in-silencer toggle and bolt-action toggle mappings.

13. MASTER INVENTORY - DIRECT HEX/STRUCTURE GUIDE
======================================================================
URL:
https://www.nexusmods.com/deusexmankinddivided/mods/37?tab=docs

Verified direct information from the author's "How to Mod Yourself" documentation:
- 8D0137A2 is the stack-size marker.
- After that marker, following the documented zero/0C structure, is the editable stack amount.
- Weapon grid width can be located by finding the weapon's *_CORE record and searching
  backward for the current width beneath the weapon-width marker corresponding to 8E6BC587.
- The author directly documents editing Game.layer.1 and relevant Enforcer/Tactical DLC archives.

Documented example changes:
- Sniper Rifle: 7x2 -> 3x2.
- Tranquilizer Rifle: 7x2 -> 3x2.
- Battle Rifle/Lancer Rifle: 6x2 -> 3x2.
- Combat Rifle/Cote d'Azur/Tactical Shotgun/Devastator: 5x2 -> 3x2.
- Machine Pistol: 4x2 -> 3x2.
- Elite Tranquilizer Rifle: 7x2 -> 3x2.
- Elite Combat Rifle: 5x2 -> 3x2.
- Grenade Launcher ammunition: 2x2 -> 1x2.
- Biocells/Hypostims/Multi-tools: 2x1 -> 1x1.
- Example stack targets include Weapon Parts 5000, weapon ammo 400, GL ammo 200,
  Multi-tools 200, Biocells/Hypostims/Painkillers/Neuropozyne 100 and augmentation ammo 100.

This independently confirms the 8D0137A2 stack marker and the weapon-grid structure already
known from Grognougnou.

======================================================================

======================================================================
